# Skill catalog

`skills.json` and `skills.md` are generated from the three runtime trees by `scripts/build-catalog.ps1`.

## Categories

- `frontend-ui` — web UI, React, Next.js, CSS, browser, motion, and visual systems
- `backend-platform` — APIs, databases, server runtimes, cloud platforms, and typed backend work
- `mobile-native` — Expo, React Native, iOS, SwiftUI, Kotlin, and Android
- `design-motion` — product design, branding, interaction, animation, and visual direction
- `security-quality` — security, accessibility, testing, audits, debugging, and performance
- `devops-delivery` — Git, deployment, CI/CD, release, and environment setup
- `data-research-content` — research, SEO, analytics, editorial, and domain expertise
- `docs-writing` — documentation, plans, specifications, PRDs, and writing workflows
- `integrations-tools` — MCP, Figma, Google, Canva, Obsidian, Firecrawl, and external tools
- `agent-workflows` — agent coordination, context, principles, GSD, and GStack workflows
- `other` — packages that do not match a stronger category rule

Category assignment is name-based and deterministic. It is for navigation only; it does not change runtime discovery or package contents.
