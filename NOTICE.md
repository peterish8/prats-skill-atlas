# Notice

Prats Skill Forge is a mirror and distribution layout for skill packages collected from local Claude, Codex, and shared agent skill directories.

The repository-level documentation and installer scripts are provided for this project. Individual skill directories may originate from different projects, authors, or vendors and may carry their own license files or usage restrictions. A repository copy does not relicense those packages. Review the nearest `LICENSE`, `LICENSE.txt`, or package documentation before commercial redistribution or modification.

Generated dependencies, caches, browser downloads, build output, bytecode, and platform-specific binaries are omitted to keep the mirror portable.
