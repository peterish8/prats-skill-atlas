# source-command-save-credits

Use this skill when the user asks to run the migrated source command `save-credits`.

## Command Template

Enter save-credits mode for the rest of this conversation:

1. No Agent/subagent spawns — think and act directly
2. Read known files directly, don't Glob/Grep to rediscover them
3. Plan the full solution mentally first, then execute in as few tool calls as possible
4. No redundant reads — if it's already in context, use it
5. Short responses — no summaries, no recaps, just do it and confirm in one line
6. Solve exactly what's asked — no abstractions, no future-proofing
7. Before every tool call, ask: is this actually needed?

Confirm with: "Save-credits mode on."
