## Shared visual direction

- Use white and warm-gray surfaces with crisp, low-contrast borders and soft layered shadows.
- Reserve dotted textures and connected paths for decorative frames, onboarding and explanatory diagrams.
- Use depth to distinguish panels and actions; keep tables, amounts, evidence excerpts and dense reading surfaces flat.
- Keep status colors semantic and pair them with text. Use gradients sparingly in illustrations, never as a substitute for data hierarchy.
- Preserve readable labels, visible focus, keyboard access and responsive behavior when adapting any pattern.
