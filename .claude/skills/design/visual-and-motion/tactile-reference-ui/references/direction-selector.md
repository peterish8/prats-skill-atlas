# Choose a direction before choosing components

This kit studies 36 supplied captures and preserves twelve distinct directions. Directions are composition rules, not twelve interchangeable accent colors. A `Theme` supplies material tokens; the page still needs the correct scale, whitespace, art placement and task flow.

If the user gives a direction, use it. Otherwise choose using the product's core action and density: a review table normally starts in signal; a one action creation page in meadow; an integration explanation in connected or systems; a product showcase in landscape. State the choice in one sentence and proceed. Offer alternatives only when they change the product experience materially.

## Permitted blending

Choose one base direction for at least the navigation, heading scale, controls and content surfaces. Borrow one bounded idea from a secondary direction: a connected map in a porcelain page; landscape stages inside an editorial feature section; a frosted icon in citrus; spectral art in an onboarding dialog. The borrowed element inherits the base typography, radii and interaction language.

Do not put meadow, prism, citrus and atelier backgrounds on adjacent sections just because all references are attractive. That produces a mood board, not a designed product. Keep semantic status colors independent from decorative palettes.
