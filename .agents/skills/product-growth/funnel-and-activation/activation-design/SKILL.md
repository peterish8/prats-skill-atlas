# Activation design

Move users to a value event that is meaningful for them and plausibly connected to repeat use, not merely easy to count.

## Workflow

1. Define the product's recurring value cycle and the user outcome it creates.
2. Generate candidate activation events from interviews, behavioral paths, and retained-versus-churned cohort comparisons.
3. Reject administrative milestones such as signup completion unless they independently represent value.
4. Measure activation rate, time to value, path completion, and later retention by cohort.
5. Identify the smallest set of prerequisites and remove or defer steps that do not protect value, safety, or informed choice.
6. Design interventions around guidance, defaults, templates, sample data, collaboration, or progressive disclosure.
7. Validate causality through experiments or clearly label predictive relationships as observational.

## Deliverable

Return:
- value-cycle and activation definition
- candidate-event evidence table
- activation funnel and time-to-value baseline
- friction diagnosis
- intervention and validation plan

## Guardrails

- Do not optimize onboarding completion as a proxy without validating downstream value.
- Do not force actions that inflate activation while harming autonomy or retention.
- Use product-specific usage intervals rather than universal day-based benchmarks.
