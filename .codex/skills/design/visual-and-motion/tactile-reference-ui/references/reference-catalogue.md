## Interpretation rules

Use a primary original image to compare layout and a secondary image to compare material. Record uncertainty rather than inventing exact fonts, tiny labels or observed animation. Rebuild original brand/content/assets appropriate to the actual product. The library provides reusable primitives and texture approximations; it does not contain replicas of the pictured websites, photographs or application screens.
