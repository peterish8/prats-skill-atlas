# Artwork and typography provenance

Created/retrieved 2026-10-12 for the standalone Tactile UI kit. Generated artwork is original project material, distinct from the 36 supplied study screenshots. The kit does not redistribute a source brand's logos or photographic crops as production artwork.

`meadow-landscape.png` was generated with the built-in image generation tool using this prompt:

> Use case: photorealistic-natural. Asset type: a premium website component-library background artwork, no UI, no typography. Create an original panoramic photograph-like landscape of smooth rolling meadow hills with soft natural green and honey yellow grasses, sparse lavender wildflowers in the immediate foreground, under a clear soft cyan blue sky with delicate white clouds. Rich real grass texture but graceful large shapes; sophisticated calm countryside atmosphere, fresh daylight and warm low sun. Wide 16:9 composition with sky occupying top third, successive hills forming elegant diagonal layers and center area visually calm for a white product card overlay. Inspired by clean nature-staged product photography in premium software sites, not cartoon or vector. No people, no buildings, no roads, no logos, no watermarks, no words or numbers, no interface or product mockup.

`iridescent-orb.png` was generated with the same built-in tool and a transparent background:

> Use case: stylized-concept. Asset type: transparent cutout original material object for an elegant healthcare-inspired web component library. Create one perfectly round, floating liquid iridescent orb viewed straight on. The center is a smooth saturated sapphire/cornflower blue translucent liquid lens, with a thin organic swirling annulus of pale butter yellow, mint green, cyan and luminous ivory around its perimeter. Fine fluid reflection details, polished glassy material with realistic optical refraction, calm refined studio light, no excessive glow. Object isolated centrally with transparent background. No text, no logo, no symbol, no stand, no scene, no border frame. The shape is mostly a blue circular globe with fluid green/cream iridescent rim, not a donut with an empty center. Intended displayed at 160-240 CSS pixels, crisp premium 3D material quality.
