# Prats Skill Atlas onboarding

You are inside **Prats Skill Atlas**, a public catalog of skills for Claude, Codex, Grok, Antigravity, and shared agents. Treat this file as the Claude-specific entry point and follow the complete shared contract in [`AGENTS.md`](AGENTS.md).

When this repository is handed to you for setup, begin with the onboarding interview in [`ONBOARDING.md`](ONBOARDING.md). Ask all 12 questions before installing anything. Use [`catalog/skills.json`](catalog/skills.json) to map the answers to exact skill packages, propose a minimal selection, and wait for the user's approval.

Do not bulk-install the atlas by default. Do not paste every `SKILL.md` into context. Read the full instructions only for the approved packages that are relevant to the user's current work. Keep installation additive and explain any package that is unavailable in Claude's runtime tree.
